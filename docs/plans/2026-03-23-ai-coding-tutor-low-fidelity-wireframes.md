## 1. 文档目标

本文档用于将“页面级原型说明”进一步落到线框级别，明确各核心页面的布局骨架、组件层级、主要状态、页面跳转与关键交互，用于：

- 产品确认页面结构是否合理
- 交互设计师开始绘制低保真 Wireframe
- UI 设计师在清晰结构上叠加视觉层
- 前端在开发前理解组件边界与信息优先级

本文档仍不处理视觉细节，不定义具体颜色、字体、插画和动效风格，这些内容归入 UI 视觉设计稿说明。

---

## 2. 线框设计原则

### 2.1 一屏一个主目标

每个页面必须存在一个最重要动作，不能让用户在首屏面对多个并列主操作。

### 2.2 主任务始终高于说明信息

- 当前任务
- 当前进度
- 当前 CTA

以上三类信息在学习流程中必须优先于说明、规则、历史、成就等信息出现。

### 2.3 学习产品优先看流程，不先看装饰

线框阶段只解决：

- 内容放在哪里
- 先看什么，后看什么
- 点击后发生什么
- 哪些状态必须可恢复

### 2.4 降低认知切换成本

- 对话区和任务区尽量保持固定位置
- 任务状态反馈尽量统一
- 页面间重复组件保持一致位置和命名

## 5. 页面一：Landing Page 线框说明

### 5.1 页面目标

- 首次访问即理解产品价值
- 说明产品不是教程库，而是学习陪练
- 推动注册转化

### 5.2 首屏结构

首屏建议采用左右双栏。

左侧内容：

- 主标题
- 副标题
- 主 CTA
- 次 CTA
- 一行简短社会证明或用户收益总结

右侧内容：

- 产品预览线框
- 预览中突出三件事：当前任务、AI 导师对话、完成反馈

### 5.3 页面模块顺序

1. Hero 首屏
2. 三步工作方式
3. 适合人群
4. 工具覆盖
5. 学习收益
6. 页面底部 CTA

### 5.4 低保真骨架

```text
+--------------------------------------------------------------------------------+
| Logo                               产品介绍  适合谁  工具覆盖      登录  开始   |
+--------------------------------------------------------------------------------+
| 左：主标题/副标题/CTA               | 右：产品界面预览                             |
| [免费开始] [查看学习方式]           | - 当前任务                                   |
| 1行价值说明                         | - AI 导师对话                                |
|                                    | - 学分升级反馈                               |
+--------------------------------------------------------------------------------+
| 三步工作方式：发内容 -> AI拆解 -> 完成任务                                      |
+--------------------------------------------------------------------------------+
| 用户人群说明                                                                  |
+--------------------------------------------------------------------------------+
| 工具卡片说明                                                                  |
+--------------------------------------------------------------------------------+
| 收益说明 + 最终 CTA                                                           |
+--------------------------------------------------------------------------------+
```

### 5.5 关键组件

- 顶部导航
- 主标题区
- 主按钮 / 次按钮
- 产品预览卡片
- 三步说明卡片
- 用户分群卡片
- 工具生态卡片

### 5.6 跳转关系

- 点击“免费开始” -> 登录 / 注册页

## 7. 页面三：欢迎页与工具选择页 线框说明

### 7.1 页面目标

- 完成第一次学习分层
- 为用户生成第一条学习路径

### 7.2 页面结构

页面采用上下布局：

- 顶部欢迎区
- 中部水平选择区
- 下部工具卡片区
- 底部确认区

### 7.3 模块拆解

#### 模块 A：欢迎信息

- 标题
- 副标题

#### 模块 B：水平选择

- 入门
- 有基础
- 系统提升

#### 模块 C：工具卡片区

按 3 个分组展示工具卡片。

每张工具卡片包含：

- 工具名称
- 难度标签
- 一句话适配场景

#### 模块 D：起点预告区

用户选中某工具后，展示：

- 推荐起点
- 学习路径前 3 步
- 主 CTA

### 7.4 低保真骨架

```text
+--------------------------------------------------------------------------------+
| 欢迎标题：先选一个方向，我们陪你从第一步开始                                   |
+--------------------------------------------------------------------------------+
| 水平选择： [刚入门] [有基础] [系统提升]                                       |
```

- 未选水平时，工具卡片不高亮

- 点击“开始我的学习路径” -> 学习主界面

## 8. 页面四：学习主界面 线框说明

### 8.1 页面目标

- 成为最核心高频学习页面
- 承载对话、任务、进度、反馈的完整学习闭环

### 8.2 页面总体结构

采用三栏固定结构：

- 左栏：路径与个人状态
- 中栏：AI 导师对话
- 右栏：当前步骤上下文

### 8.3 左栏结构

从上到下：

1. 当前工具
2. 当前路径名称
3. 任务列表
4. 历史记录入口
5. 学分与段位
6. 连续打卡

### 8.4 中栏结构

从上到下：

1. 当前任务标题条
2. 对话消息流
3. 快捷操作条
4. 输入区

#### 当前任务标题条包含

- 任务名称
- 关卡编号
- 状态标签
- 小型进度条

#### 对话消息流包含

- AI 消息
- 用户消息
- 系统反馈消息

#### 快捷操作条

- 帮我拆细一点
- 我卡住了
- 给我一个例子
- 我已经做完了

#### 输入区

- 多行输入框
- 发送按钮
- 粘贴链接入口
- 粘贴代码入口

### 8.5 右栏结构

从上到下：

1. 当前这一步
2. 完成标准
3. 涉及知识点
4. 常见卡点
5. 下一步预告

### 8.6 低保真骨架

```text
+------------------------------------------------------------------------------------------------+
| 顶部栏：Logo | 学习 | 地图 | 成就 | 历史 | 学分 | 段位 | 连续学习                               |
+------------------------------------------------------------------------------------------------+
| 左栏：路径/任务               | 中栏：AI导师对话                     | 右栏：当前步骤上下文   |
| - 当前工具                    | 当前任务标题                          | 当前这一步             |
| - 第1关 已完成                |--------------------------------------| 完成标准               |
| - 第2关 已完成                | AI：今天先完成这一步                  | 知识点                 |
| - 第3关 进行中                | 用户：我已经装好了                    | 常见卡点               |
| - 第4关 未开始                | AI：很好，下一步请你...               | 下一步预告             |
| 历史记录                      |--------------------------------------|                       |
| 学分/段位/打卡                | [拆细] [卡住了] [给例子] [做完了]      |                       |
|                              | 输入框 + 发送                         |                       |
+------------------------------------------------------------------------------------------------+
```

### 8.7 关键状态

- 初次进入空态
- 恢复上次学习态
- AI 思考中
- 卡住求助态
- 任务完成态
- 链接解析失败态

### 8.8 页面行为

- 输入内容并发送 -> 生成 AI 引导
- 点击“我已经做完了” -> 完成反馈弹层
- 点击“我卡住了” -> 求助浮层
- 点击左栏任务节点 -> 切换当前任务上下文

## 9. 页面五：闯关地图页 线框说明

### 9.1 页面目标

- 让用户看到整体学习路径
- 明确自己当前所在位置
- 支持回顾和重新进入某一关卡

### 9.2 页面布局

- 顶部路径总览
- 中部地图主区
- 右侧或浮出详情区

### 9.3 地图节点规则

每个节点至少显示：

- 关卡名称
- 状态
- 简要目标

节点状态：

- 已完成
- 当前进行中
- 未解锁

### 9.4 低保真骨架

```text
+--------------------------------------------------------------------------------+
| Cursor 学习路径        已完成 2/5        当前进度 40%                          |
+--------------------------------------------------------------------------------+
|  ● 第1关 认识界面   已完成                                                     |
|  |                                                                             |
|  ● 第2关 第一个Prompt 已完成                                                   |
|  |                                                                             |
|  ◎ 第3关 生成第一个页面 进行中      -> 右侧详情区                               |
|  |                                                                             |
|  ○ 第4关 连接数据库 未解锁                                                     |
|  |                                                                             |
|  ○ 第5关 部署上线 未解锁                                                       |
+--------------------------------------------------------------------------------+
```

### 9.5 详情区内容

- 本关目标
- 完成条件
- 知识点
- 上次进度
- 进入学习按钮

### 9.6 页面行为

- 点击当前节点 -> 回到学习主界面对应任务
- 点击已完成节点 -> 打开回顾说明
- 点击未解锁节点 -> 展示解锁条件

## 13. 页面流转说明

核心流程如下：

1. Landing Page -> 登录 / 注册页
2. 登录 / 注册页 -> 欢迎页与工具选择页
3. 工具选择页 -> 学习主界面

6. 学习主界面 -> 各类弹层反馈

## 15. 交付建议

建议 UI/交互设计阶段按以下顺序推进：

1. 先画学习主界面低保真稿
2. 再补工具选择页
3. 再补 Landing Page
4. 最后补地图页和成就页

原因：

- 学习主界面是产品核心
- 工具选择页决定首轮转化
- Landing Page 决定拉新，但依赖产品表达已经清晰

---

## 16. 结论

低保真线框的核心目标，是先把这个产品最关键的结构问题定住：用户怎么进入、怎么开始、怎么持续、怎么回到上次位置、怎么感知进步。只要这几件事在线框层面是清楚的，后续的视觉设计和前端实现都会更稳定。

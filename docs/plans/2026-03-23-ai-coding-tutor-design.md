## 一、产品定位

**一句话定位**
> 你负责找教程，我负责陪你真正学会——专注AI编程工具的智能学习教练

**核心差异化**
不是内容平台，是学习执行层：

```
传统学习路径：找教程 → 收藏 → 浅看 → 忘记
我们的路径：  找教程 → 发给AI → AI拆解 → 手把手陪练 → 真正落地
```

**市场定位**
- 主打中国市场，中文产品
- 微信登录 + 国内支付
- 覆盖国内外主流AI编程工具生态

## 四、核心功能模块

### 4.1 AI导师对话（核心引擎）

用户输入方式：
- 粘贴教程文字 / 代码片段
- 发送 YouTube / B站 / 抖音链接
- 上传截图

AI导师行为逻辑：
```
1. 解析内容 → 提炼关键知识点
2. 苏格拉底式引导 → 不直接给答案，只问引导性问题
3. 拆解成"今天只做这一步" → 降低启动门槛
4. 用户卡住时 → 给提示而不是答案
5. 完成后 → 总结学到了什么，指向下一步
```

### 4.2 傻瓜式实战任务（闯关系统）

像游戏关卡一样推进，永远只展示"下一步"：

```
第1关 ✅  认识工具界面
第2关 ✅  写第一个Prompt
第3关 🔄  用AI生成第一个页面  ← 当前位置
第4关 ⬜  连接数据库
第5关 ⬜  部署上线
```

每关完成 → 动画庆祝 + 学分入账

### 4.3 学习路径追踪

- 自动记录用户学过什么、卡在哪里
- 生成个人技能图谱
- 每次回来自动续接上次进度

### 4.4 学分奖励机制

**获得方式：**

| 行为 | 学分 |
|------|------|
| 完成实战任务步骤 | +10 |
| 每日打卡 | +20 |
| 完成完整项目 | +100 |
| 分享学习成果 | +30 |
| 提交好教程 | +25 |
| 帮助社区其他用户 | +15 |

**段位系统：**

```
🌱 萌新码农     0 - 200分
⚡ AI学徒       200 - 500分
🔥 Vibe Coder   500 - 1000分
🚀 AI建造者     1000 - 2000分
💎 AI编程大师   2000分以上
```

**学分兑换：**
```
初级成就 → 解锁更多AI对话次数
中级成就 → 解锁进阶实战任务
高级成就 → 免费获得订阅时长
顶级成就 → 专属"AI编程认证徽章"（可放简历）
```

**社交裂变：**
- 学分排行榜（周榜/月榜）
- 成就卡片一键分享朋友圈
- 邀请好友双方各得学分

## 六、界面设计

### 风格定位
```
参考：Linear + Duolingo 的结合
- Linear 的简洁专业感
- Duolingo 的游戏化轻松感
色调：深色主题为主，亮色点缀成就/进度
```

### 核心页面

**1. 首页（Landing Page）**
```
① 一句话价值主张
   "把你收藏的AI编程教程，真正变成你的技能"
② 三步说明
   发入教程链接 → AI导师拆解陪练 → 完成任务得学分
③ 社会证明
④ 免费开始按钮
```

**2. 选择工具页**
```
工具卡片网格展示
用户选定工具 → 进入专属学习路径
```

**3. 学习主界面**
```
左侧栏：学习路径 / 今日任务 / 学分段位 / 历史记录
中间区：AI导师对话框（主要空间）
右侧栏：当前知识点进度 / 今日学分 / 下一步提示
```

**4. 闯关地图**
```
游戏化关卡视图，清晰看到当前位置和整体进度
```

**5. 个人成就页**
```
技能图谱 + 学分 + 段位 + 连续打卡天数 + 分享卡片
```

### 关键UX原则
```
1. 永远只展示"下一步" — 避免压迫感
2. 每次对话结束有明确收获感
3. 卡住了不孤单 — AI主动问"你卡在哪里了？"
4. 进度永远可见 — 顶部进度条 + 学分实时更新
```

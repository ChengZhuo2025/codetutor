# 侧边栏学习提醒优化设计方案

## 背景与问题

当前 `DashboardSidebar` 中"学习提醒"组件存在两个核心问题：

1. **逻辑矛盾**：用户同一天收到"今天还没打卡"和"今日打卡成功"两条互相排斥的通知
2. **布局挤压**：提醒区域位于导航菜单上方，当通知较多时将导航菜单推到视口外，需滚动侧边栏才能看到

## 设计目标

- 导航菜单始终在第一屏可见，不被提醒内容挤压
- 消除同源互斥通知同时展示的矛盾
- 简化提醒卡片样式，减少视觉噪音

## 方案概述

> **提醒移至导航菜单下方 + 折叠卡片 + 列表行 + 弹框详情**

提醒组件从"用户资料卡下方"迁移到"导航菜单下方"，改为折叠卡片。列表行仅显示图标 + 标题 + 状态标签，点击行打开详情弹框进行操作。

## 详细设计

### 1. 布局结构调整

**调整前后对比：**

| 顺序 | 调整前（当前） | 调整后 |
|------|--------------|--------|
| 1 | Logo | Logo |
| 2 | 用户资料卡 | 用户资料卡 |
| 3 | **学习提醒（展开）** ← 问题区 | **导航菜单** ← 始终可见 |
| 4 | 导航菜单 | **学习提醒（折叠）** ← 新位置 |
| 5 | 最近学习 | 最近学习 |
| 6 | 设置 | 设置 |

### 2. 矛盾通知处理逻辑

**问题根源**：后端同一用户同一天生成了两条互斥通知（打卡状态不一致）。

**前端解决方案**：在 `WorkspaceSidebarDataProvider` 中对 `notifications` 数组做预处理——按 `source` + `date` 分组，每组只保留最新一条（`createdAt` 最晚）。

**注意**：前端过滤是展示层兜底，后端仍需排查事件流，修复打卡状态变更时的通知生成逻辑，避免重复/互斥通知产生。

### 3. 折叠卡片交互

**收起状态（默认）**：
```
🔔 学习提醒              2 条未读    [▼]
```
- 可点击整行或箭头切换折叠状态
- 显示未读数徽章（无未读时显示"已读完"）

**展开状态**：
```
🔔 学习提醒              2 条未读    [▲]
────────────────────────────────────────
✅ 今日打卡成功                       未读  >
⚠️ 你已完成今日打卡                  已读  >
```

- 列表行只显示：图标 + 标题 + 状态徽章 + 展开箭头
- 平滑 height 动画过渡
- 折叠状态不持久化，每次刷新页面重置为收起

### 4. 详情弹框交互

**触发**：点击列表任意行

**弹框内容**：
```
┌─────────────────────────────────────┐
│  今日打卡成功                    [×] │
├─────────────────────────────────────┤
│                                     │
│  继续保持，连续学习 3 天             │
│                                     │
│  时间：今天 09:12                    │
│                                     │
├─────────────────────────────────────┤
│  [        去打卡        ]            │
│  [        忽略          ]            │
└─────────────────────────────────────┘
```

**打开时行为**：
- 若当前状态为 `unread`，静默调用 `markNotificationRead` API（不阻塞弹框展示）
- 弹框内容直接渲染 `notificationItem` 数据

**操作按钮**：
- 主要按钮：根据 `actionHref` + `actionLabel` 渲染，点击后跳转并关闭弹框
- 次要按钮（忽略）：调用 `dismissNotification` API，成功后关闭弹框

**关闭行为**：
- 点击遮罩层 / [×] / ESC 键 → 关闭，无任何操作
- 操作完成后自动关闭

**状态刷新**：成功后 `WorkspaceSidebarDataProvider` 实时更新列表，无需刷新页面。

### 5. 空状态

折叠内容区内无任何通知时（互斥处理后）：
```
暂无新提醒。完成打卡或任务后，新的提醒会出现在这里。
```

## 涉及文件

| 文件 | 改动 |
|------|------|
| `components/layout/dashboard-sidebar.tsx` | 调整内容顺序、重构提醒区为折叠卡片 |
| `components/layout/notification-detail-dialog.tsx` | 新建：通知详情弹框组件 |
| `providers/workspace-sidebar-provider.tsx` | 添加同源通知互斥预处理逻辑 |

## 实现顺序

1. 后端矛盾通知排查（可选但建议）：检查打卡状态变更事件流，防止重复通知产生
2. `providers/workspace-sidebar-provider.tsx`：添加同源通知互斥预处理
3. 新建 `components/layout/notification-detail-dialog.tsx`
4. 重构 `components/layout/dashboard-sidebar.tsx`：调整布局 + 折叠卡片 + 调用弹框
